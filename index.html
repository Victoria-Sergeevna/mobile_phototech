Как установить в Outlook
  1. Заполните поля выше.
  2. Нажмите «Поделиться / Скопировать» → «Копировать».
  3. Откройте Outlook → Настройки → Подписи.
  4. Создайте новую подпись, сделайте долгое нажатие в поле → «Вставить».
  5. Сохраните и отправьте себе тестовое письмо.

Подсказка для телефона: если «Поделиться / Скопировать» открыло системное меню — выберите «Копировать». Если копирование недоступно, нажмите «Выделить подпись вручную» и сделайте долгое нажатие по выделению → «Копировать». В Outlook — долгое нажатие в поле подписи → «Вставить».
